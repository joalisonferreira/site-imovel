Imóvel Parceiro Core
====================

Este plugin cria uma camada de extensão integrada ao Houzez 4.3.5 para:
- aceitar termos obrigatórios na publicação de imóveis;
- registrar aceites por usuário e imóvel;
- solicitar e gerir parcerias;
- alimentar oportunidades e negócios;
- gerar comissões e expor um dashboard frontend.

Instalação
----------
1. Copie a pasta do plugin para wp-content/plugins/.
2. Ative o plugin no WordPress.
3. Acesse o dashboard do Houzez para visualizar o módulo.

Observação
----------
A integração foi construída com base na análise do ambiente real do Houzez e do CRM existente, reutilizando o fluxo de dashboard e de publicação do tema.
